# BMP REST — Restaurant Management System

Restaurant module of the BMP platform. Fully isolated from the school module.

## Live URL
https://mpbusiness-mr.github.io/BMP-REST/

## Backend
- Google Apps Script project: **BMP REST Backend**
- Deployment URL: `https://script.google.com/macros/s/AKfycbzTivPDnfsW6V0mwiXAlz7zj26LSZIU3P0VQEzjFlXsZxEZrAbWyxQ1XUpmS_5Q7VYq2w/exec`
- Master spreadsheet: `rest-admin-credts`

## Files
- `index.html`            — redirects to `rest.login.html`
- `adminlogin.html`       — platform admin login
- `rest.login.html`       — restaurant login
- `rest.html`             — restaurant dashboard (single page + modals)
- `rest.settings.html`    — restaurant settings + change password + users

## Auth
- Admin session key:      `bmpAdminUser`
- Restaurant session key: `bmpRestaurantUser`

Arabic / Français / English
